## 1. 产品定位

AI 基于用户提供的简历和知识集进行多轮模拟面试，支持历史对话记录 / 断点续聊。产品名 **AI 面试官**。单机本地工具，无账号体系。

## 2. 范围与分期

| 阶段 | 交付范围 | 退出条件 |
|---|---|---|
| P0 | LLM 集成 + FastAPI/SSE + Vue 3 前端 + `MemorySaver` 内存续聊 + 会话管理 + 面试场景（实习/全职）+ 环境配置 + 基础报告 | P0-1 ~ P0-8 验收通过 |
| P1 | 知识集入库（轻量解析 MD/TXT/DOCX/PDF → 父子切块 → Qdrant+ES 双路召回）+ RAG 检索问答 + 四级降级 + 引用标注 + Embedding 模型可切换 | P1-1 ~ P1-7 验收通过 |
| P2 | 简历解析 + 个性化题库 + 出题图 + `SqliteSaver` 跨重启持久化 + `web_verify` 可选节点 | P2-1 ~ P2-5 验收通过 |

**本期不包含**：多人/群面、语音与视频面试、简历批量筛选、对外付费与账号体系。

## 3. 项目边界（2026-09-15 确认）

| 边界项 | 约定 |
|---|---|
| 部署形态 | 单机本地：后端绑定 127.0.0.1，无账号鉴权，无跨机 CORS 暴露 |
| 数据生命周期 | 删除即物理删：会话/简历/知识库删除时，SQLite、Qdrant、ES 三处同步删，不留副本 |
| 并发边界 | 同会话同一时刻仅一个流式回复（R6）；跨会话**全局单流式**，同时仅一个会话可流式回复，其余排队 |
| 单用户模型 | 无多用户隔离、无权限分级 |
| API Key 存储 | 明文 .env（gitignore）+ python-dotenv；日志与前端展示一律掩码（sk-•••） |

## 4. 功能需求摘要

### F1 会话管理 [P0]
- 会话列表（标题/场景徽标/进度/状态）+ 新建面试配置弹窗
- 新建字段：面试场景（实习/全职，默认全职）、面试类型（技术面/行为面/综合，默认技术面）、岗位方向（≤50 字必填）、关联知识库 [P1]、关联简历 [P2]、题目数量（5–30，默认 10）
- 状态：进行中 ↔ 已完成；删除需二次确认；空态引导
- 断点续聊：P0 内存态（后端重启丢失并提示），P2 SqliteSaver 跨重启持久化

### F2 面试对话 [P0/P1/P2]
- AI 按题库顺序出题（P0 通用题库；P1 知识检索出题 + 引用标签；P2 简历项目深挖）
- 场景差异：**实习**以基础概念、八股要点与项目介绍为主，不追求复杂场景题，不深挖底层原理；**全职**常规面试深度，可涉及场景设计与原理追问；**两场景追问同轮次（1–2 轮）**
- 回答 ≤ 5000 字；提示一下每题 ≤ 1 次（不计分）；跳过此题标记「未作答」；进度条
- 全部答完或用户结束 → 报告生成（F5）；SSE 逐 token 流式渲染

### F3 简历管理 [P2]
- 上传 PDF（含文字层）/ docx ≤ 20MB；Docling 解析 → 结构化抽取 → 自动构建题库（≥10 题）
- 失败展示原因（如扫描件无文字层）+ 重新上传；异步任务

### F4 知识库管理 [P1]
- 上传 PDF/DOCX/MD/TXT ≤ 50MB；父子切块（父块 ≤800 字、子块 ≤200 字）；Qdrant 向量 + ES 全文（ik_max_word）
- 检索设置：语义/关键词权重滑块（0–1 步进 0.05）、Top-K 默认 5；删除级联清理
- Embedding 模型可配置（本地 bge-large-zh-v1.5 / 外部 API）；知识库绑定 model_id + 维度，切换模型需重建索引；外部 API 选项展示「内容外发第三方」提示

### F5 面试报告 [P0/P2]
- 总分环形图 + 四维度（技术深度/沟通表达/逻辑思维/项目经验）+ 优缺点双栏 + 关键问题回顾表
- 「再来一场」复用本次配置；「导出报告」下载为 **Markdown**
- P2 起 web_verify 校验事实性陈述（已核验/存疑/无法确认 + 信源链接）

### F6 环境配置 [P0]
- LLM API Key（DeepSeek，必填，`sk-` 前缀校验，掩码展示 + 显示切换）
- Embedding 配置 [P1]（可选：本地 bge-large-zh-v1.5 / 外部 API，切换触发知识库重建）、联网搜索 Key [P2]（可选）
- Key 仅存后端（.env/gitignore）；**新会话用新 Key，进行中会话沿用旧 Key**
- 未配置 Key 时新建/继续会话被拦截并提示；测试连接失败不保存

## 5. 规则

- **R1 面试场景**：实习/全职固定于会话创建时；出题深度按场景区分；两场景追问同轮次（1–2 轮）
- **R2 降级**：LLM 超时/限流重试 1 次，仍失败 → fallback 文案 + warning 日志；知识不足时 normal/weak/fallback/decline 四级降级（P1）
- **R3 提示**：每题最多 1 次，提示不计入评分
- **R4 web_verify** [P2 待确认触发方式]：事实性回答联网校验，标记相关/冲突/无法确认并附信源
- **R5 存储**：知识集 Qdrant+ES 级联删除；配置（API Key）不入库、不入版本控制
- **R6 边界异常**：检索单点故障 → 单路降级 + 告警；入库失败保留原文件可重试；输入服务端二次校验；并发「上一回复生成中」提示

## 6. 验收标准（摘要）

### A · 工程（A-1~A-5）
uv sync 可复现 / ruff 无错误 / pre-commit 可运行；loguru 关键节点日志；omegaconf 统一配置 + Key 仅 .env；前端无 console 报错；并发会话数据隔离。

### P0 · 可对话 MVP（P0-1~P0-8）
SSE 5s 内首 token 流式渲染；连续 20 轮无状态串扰；刷新可续聊（内存）；会话 CRUD 全流程；5 并发无崩溃；基础报告（总分+四维+优缺点）；实习/全职场景可选且出题难度区分 + 徽标展示；Key 可自配 + `sk-` 校验 + 未配置拦截。

### P1 · 知识库 + RAG（P1-1~P1-7）
入库成功率 ≥95%；50 题 Top-K=5 召回命中率 ≥80%；normal 级引用准确率 ≥90%；四级降级路径正确；删除级联清理 0 命中；单次检索 P95 ≤2s；Embedding 切换后重建索引，查询模型与库绑定模型一致（P1-7）。

### P2 · 简历 + 持久化（P2-1~P2-5）
20 份简历解析成功率 ≥90%、字段抽取 ≥85%；每份简历 ≥10 题且 ≥80% 相关；重启后会话完整恢复；web_verify 返回信源且标记正确；端到端链路可用。

### N · 非功能（N-1~N-9）
完整回复 P95 ≤15s + TTFT P95 ≤3s；上传 ≤10MB 校验 + 路径安全 + Key 掩码；异常业务文案无堆栈；Qdrant/ES docker-compose 一键起 + 缺失降级；结构化 JSON 日志 + 耗时/token 明细 + TTFT>5s 告警；Chrome/Edge 近 2 主版本 + Safari 17.4+；全局单流式排队提示；删除即物理删三处同步；端口 8000 可配 + 心跳 15s + 上传 10MB。

| 决策点 | 结论 |
|---|---|
| 产品名 | **AI 面试官**（路由 `ai-interviewer.app`，全局统一） |
| 题目数量 | 默认 10（5–30） |
| 提示次数 | 每题 1 次 |
| 追问轮次 | 实习/全职同轮次（1–2 轮），难度差异靠题目本身 |
| Key 校验 | `sk-` 前缀 |
| Key 生效 | 新会话新 Key，进行中沿用旧 Key |
| 报告导出 | Markdown |
| 断点续聊 | P0 MemorySaver（重启丢失并提示），P2 SqliteSaver |
| Embedding 模型 | 可配置：本地 bge-large-zh-v1.5 / 外部 API；知识库绑定 model_id，切换需重建索引；外部 API 加数据外发提示 |

### P1 已确认决策（2026-09-16）

| 决策点 | 结论 |
|---|---|
| 检索环境 | 本机 Docker 就绪；docker-compose 一键起 Qdrant + ES（ik 分词，N-4） |
| 知识库管理 UI | 最小可行集：上传/列表/删除/会话关联/Embedding 切换；权重滑块（F4）后置，后端固定默认值可配置化 |
| RAG 注入点 | 仅出题注入（F2「知识检索出题 + 引用标签」）；评估复用出题检索结果做事实校准（方案 A：不新增检索调用；无引用时完全退化纯 LLM 评估） |
| 降级相关性阈值 | **0.6**（≥0.6 走 normal，否则逐级降级；可配置） |
| 引用标注形态 | 题干 [1][2] 角标 + 出题消息附「知识来源」折叠列表（块标题/所属文件，可核对 P1-3） |
| 外部 Embedding 接入 | **Embedding 抽象保留**：本地 bge-large-zh-v1.5 / OpenAI-compatible embedding 可切换（base_url/api_key/model 可配置），数据外发提示；**LLM 不做抽象，本轮仅支持 DeepSeek**（LLMProvider 抽象取消） |
| 文档解析 | 轻量渐进：MD/TXT 直接切块、DOCX 用 python-docx、PDF 用 pdfplumber（无文字层提示失败）；Docling 后置 |
| 关联知识库 | 单选 + 可不关联（空 = 通用题库模式，P0 行为保留；知识不足时走降级） |
| 知识库元数据存储（P1-5 澄清） | **SQLite kb.db**（库/文件条目/processing·ready·failed 状态/绑定 model_id·dims）；跨重启可靠，删除级联有据（符合 R5 物理删） |
| 入库执行方式（P1-5 澄清） | **后台任务 + 状态轮询**：上传接口即返 processing，前端轮询至 ready/failed；失败保留原文件可重试（F4 异步任务 + R6） |
| Embedding 切换重建（P1-5 澄清） | **切换即自动重建**：配置页保存新模型弹确认（提示重建 N 个库与耗时、外部 API 外发提示）→ 后台逐库重新嵌入并更新绑定 model_id（P1-7） |
| 知识库组织（P1-5 澄清） | **先建库后传文件**：一库多文件；会话关联单选到「库」粒度；引用标注显示所属文件 |
